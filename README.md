# Sistema de Reservas - Hotel Kwanza Palace
## 🏨 Sobre o Projeto

Este sistema foi desenvolvido como parte do **Laboratório #08** da disciplina de **Engenharia de Software I**. O objetivo é informatizar a gestão do Hotel Kwanza Palace, permitindo o controle de quartos, clientes, reservas, pagamentos e serviços adicionais.

O projeto foca na aplicação prática de **Orientação a Objetos**, abrangendo desde a modelagem conceitual (Modelo de Domínio) até a implementação técnica em Java usando os princípios de SOLID.
